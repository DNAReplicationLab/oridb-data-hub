OriDB data hub

Genome-wide DNA replication datasets curated for OriDB, served as a UCSC track hub.

Tracks show relative DNA copy number measured by high-throughput sequencing, on a scale where 1 is unreplicated and 2 is fully replicated. Each dataset directory carries a dataset.json recording its source accessions, strains, per-sample statistics and file checksums.

Source and issue tracker: DNAReplicationLab/oridb-data-hub.
